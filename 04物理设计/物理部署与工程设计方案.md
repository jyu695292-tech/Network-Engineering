## 1 总体物理架构设计
### 1.1 物理拓扑总览
本项目物理架构与三层逻辑架构一一对应，采用「中心核心机房—区域汇聚机房—楼栋弱电间—宿舍终端点位」四级物理节点，全网采用万兆光纤骨干、六类双绞线水平接入的物理链路架构。

物理连接链路：
宿舍面板AP → 楼层弱电间POE接入交换机 → 楼栋垂直光缆 → 区域汇聚机房 → 校园中心机房核心设备 → 出口防火墙 → 互联网

### 1.2 物理节点层级划分
1. 一级节点：学校网络中心核心机房，部署核心交换机、防火墙、AC控制器等核心设备。
2. 二级节点：东、西、中、新四大片区各1座区域汇聚机房，部署区域汇聚交换机。
3. 三级节点：每栋楼首层/楼层弱电竖井，部署楼层POE接入交换机、配线架。
4. 四级节点：每间宿舍内86面板信息点，部署Wi-Fi 6面板AP。

## 2 设备物理部署设计
### 2.1 核心层设备部署
1. 部署位置：学校网络中心核心机房标准机柜内。
2. 设备形态：框式核心交换机，双主控、双电源冗余配置。
3. 部署规范：核心设备占用机柜U位居中部署，上下预留散热空间；所有链路采用双上行冗余，分别连接不同业务板卡。
4. 配套设备：出口防火墙、无线AC控制器、认证服务器同机房部署，统一接入核心交换机。

### 2.2 汇聚层设备部署
1. 部署位置：四大片区各自独立的区域机房内。
2. 设备形态：盒式万兆汇聚交换机，双电源冗余。
3. 部署规范：每机房配置1台汇聚交换机，安装于标准19英寸机柜；采用双万兆光纤链路上联核心交换机，实现链路冗余。
4. 机房配套：每机房配置ODF光纤配线架，统一端接楼内垂直光缆与骨干光缆。

### 2.3 接入层设备部署
1. 部署位置：各楼栋楼层弱电竖井/弱电间内。
2. 设备形态：24口/48口千兆POE接入交换机，支持POE+供电。
3. 部署规范：弱电间内安装壁挂机柜/开放式机架，交换机上架固定；每楼层交换机负责本楼层所有宿舍AP接入，上联端口采用光纤双链路上行至楼栋汇聚节点。
4. 数量配置：按每楼层宿舍数匹配端口数量，预留10%备用端口。

### 2.4 无线AP物理部署
1. 部署位置：每间宿舍室内墙面86面板位，替换原有普通网络面板。
2. 安装规范：采用标准86暗盒安装，底边距地30cm，与强电面板间距≥30cm；面板水平安装，指示灯朝上。
3. 点位原则：一间宿舍一台面板AP，信号覆盖全屋，规避墙体衰减；阳台、卫生间等附属区域由相邻房间AP补盲覆盖。
4. 供电方式：由楼层POE交换机通过六类网线远程供电，无需单独布设强电。

### 2.5 配套设备部署
1. 无线AC控制器：旁挂核心交换机，同机房部署，负责全网AP管理。
2. 认证与审计服务器：部署于核心机房DMZ区，对接校园统一身份认证系统。
3. 网管平台：部署于核心机房，实现全网设备可视化运维。

## 3 综合布线物理设计
### 3.1 布线总体架构
采用标准综合布线分级架构，垂直干线采用万兆单模光纤，水平布线采用六类非屏蔽双绞线，所有链路满足千兆到终端、万兆做骨干的传输要求。

### 3.2 垂直干线子系统
1. 线缆选型：楼栋垂直主干采用12芯单模光缆，区域骨干采用24芯单模光缆。
2. 布线路由：利旧楼内原有垂直桥架，光缆绑扎固定，转弯处留冗余弧度。
3. 端接规范：光缆两端端接于ODF光纤配线架，采用SC/UPC接头，每芯熔接损耗≤0.3dB。
4. 冗余设计：每栋楼垂直光缆预留2芯备用，区域骨干链路预留4芯备用。

### 3.3 水平布线子系统
1. 线缆选型：全部采用六类非屏蔽双绞线（UTP），满足千兆传输与POE供电要求。
2. 布线路由：从楼层弱电间出发，沿水平管线/桥架敷设至宿舍信息点，链路长度≤90米。
3. 端接规范：两端均采用T568B标准端接，水平链路端接于配线架，宿舍端接于AP面板。
4. 施工要求：线缆自然平直，无强扭、硬拉、挤压；与强电线路平行间距≥30cm，交叉处垂直跨越。

### 3.4 设备间配线设计
1. 机柜配置：弱电间配置标准壁挂机柜/落地机柜，内置理线架、24口六类配线架、光纤终端盒。
2. 配线规范：交换机端口与配线架端口一一对应，采用1米短跳线连接；所有跳线整齐绑扎，标签清晰。
3. 理线要求：强弱电分离，数据线缆与电源线缆分两侧布放；机柜内线缆走线清晰，无杂乱缠绕。

### 3.5 标签与标识规范
1. 所有线缆两端粘贴标签，标注起止设备与端口编号，命名规则与项目通信规范一致。
2. 配线架端口、交换机端口、ODF法兰位均粘贴对应标签。
3. 设备正面粘贴设备名称标签，机柜正面粘贴区域与编号标识。

## 4 供电与机房环境设计
### 4.1 POE供电设计
1. 供电标准：全网AP采用802.3af/at标准POE供电，由接入交换机统一供电。
2. 功率核算：单台AP最大功率15W，24口POE交换机整机POE功率≥370W，满足满负荷供电需求。
3. 供电保护：接入交换机支持POE端口过载保护、短路保护，故障端口自动断电隔离。

### 4.2 设备机房供电
1. 核心机房：采用双路市电输入+UPS不间断电源，后备时间≥2小时，核心设备全部接入UPS。
2. 区域汇聚机房：采用单路市电+小型UPS，后备时间≥30分钟，保障汇聚设备断电不掉线。
3. 楼层弱电间：接入交换机采用市电供电，接入配电箱空开单独回路。

### 4.3 机房物理环境要求
1. 温湿度：核心机房温度18-26℃，相对湿度30%-70%；区域机房温度10-30℃。
2. 防雷接地：所有机房做等电位接地，设备机柜可靠接地，接地电阻≤4Ω；光缆入室做金属加强芯接地。
3. 消防与防护：机房符合校园消防安全规范，配备气体灭火/干粉灭火器；机房具备防鼠、防尘能力。

## 6 物理安全设计
### 6.1 设备物理防护
1. 核心机房、区域机房安装门禁，仅授权人员可进入；机柜全部上锁。
2. 楼层弱电间加装门锁，防止非授权人员触碰设备与线路。
3. 室外光缆采用管道/桥架防护，避免外力破坏。

### 6.2 防雷与接地
1. 电源侧加装电源防雷器，网络侧加装信号防雷器，分级防护。
2. 所有设备金属外壳、机柜、桥架均可靠接地，形成等电位网络。
3. 光缆入室处金属加强芯、铠装层可靠接地，防止感应雷侵入。
