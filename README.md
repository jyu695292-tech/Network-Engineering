# 校园宿舍 Wi-Fi 6 网络工程项目

> 本仓库是校园宿舍网的**方案设计与实施模板**。文档没有现场竣工证明或真实采购清单；V1.1 中的设备型号/数量为按现有需求推导的建议基线，不应描述为已部署。

## 项目简介

项目目标是为东、西、中、新四个片区共 34 栋宿舍楼提供 Wi-Fi 6 宿舍覆盖，并形成统一认证、安全隔离和运维体系。总体采用双核心、区域汇聚、楼层 PoE 接入、Fit AP + AC 的校园网架构；宿舍业务 VLAN 网关终结在双核心，出口经防火墙，AP 业务本地转发。

**首要阅读**：[统一规划基线 V1.1](00-统一规划基线.md)。它是所有设计、拓扑和配置示例的唯一参数来源。重点修正包括：实际 3,849 AP/203 个楼层接入点、AP 与设备管理网分离、双楼层上联所需区域汇聚由 4 台改为 14 台、每栋楼一个 /24 业务 VLAN、统一网关与路由约定、PoE/光纤和设备选型校验。

## 网络关键参数速览

- 实际楼栋/楼层/AP：东13栋×5层×13间=845；西12×5×13=780；中2×11×12=264；新7×8×35=1,960；共34栋、203层、3,849 AP。
- 业务 VLAN：东1001–1013，西2001–2012，中3001–3002，新4001–4007；各 VLAN 对应一个楼栋 /24。
- 网络设备管理：VLAN999 / 192.168.99.0/24；AP 管理：VLAN998 / 192.168.64.0/19；OSPF Transit：VLAN997 / 192.168.100.0/27；内部基础服务：VLAN996 / 192.168.96.0/24；DMZ：VLAN888 / 192.168.88.0/24。
- 路由：OSPFv2 Area 0 在 VLAN997 建邻；双核心 VRRP 为楼栋 /24 提供 `.1` 网关；核心默认路由到防火墙，防火墙需配业务回程路由。
- 接入：每层 PoE 交换机两条 GE 光纤上联到两个不同汇聚故障域；MSTP 负责环路控制，未验证堆叠/MLAG 前不能称双链路均转发。

## 使用提醒

1. `config/` 内所有 `.cfg` 仅是教学/评审用示例；必须按准确硬件子型号、VRP版本、接口映射、现网地址、许可、认证平台和变更窗口修改并实验室验证。
2. 任何实际变更前，先备份现网配置并准备回滚步骤。禁止把示例口令、保留地址或“示例公网IP”直接用于生产。
3. 拓扑图由 `assets/*.mmd` 源文件生成；SVG 是派生图，源文件与参数基线不一致时以基线/审核后的 Mermaid 为准。
4. 真实施工前完成楼层逐层勘察、纤芯/ODF核对、无线勘测、PoE测量、设备软件/License确认、吞吐量和预算复核。
