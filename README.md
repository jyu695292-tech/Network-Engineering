# 校园宿舍WiFi园区网络工程项目
> 课程设计 / 毕业设计：高校宿舍园区网络整体设计方案，华为设备组网。

## 项目简介
本项目为本人在广西某网络公司实习时所做的某高校宿舍园区网络工程设计，采用**核心‑汇聚‑接入三层园区网架构**，无线使用AC旁挂核心 + Fit瘦AP模式。
实现多楼栋宿舍有线+无线全覆盖，完成VLAN划分、IP规划、OSPF动态路由、Portal‑Radius无线认证、内网安全防护、QoS带宽管控，包含完整需求、设计、实施、配置、运维全套工程文档。



## 网络架构
- 架构模型：三层园区网（核心层 / 区域汇聚层 / 楼栋接入层）
- 无线模式：AC旁挂核心 + Fit AP，AP本地转发
- 内网路由：OSPF Area 0 单骨干域
- 出口安全：USG6000防火墙做边界安全、NAT
- 认证体系：Portal + Radius 无线实名上网

## 软件环境
- 文档编辑：VS Code + Markdown插件 / Typora
- 拓扑绘图：DrawIO，输出`.svg`矢量图存放在assets
- 模拟仿真：eNSP / HCL华为模拟器，可导入cfg配置参考
- 版本管理：Git

## 如何打开本项目
1. 将仓库克隆/下载到本地，**路径不要包含中文、空格**
2. 使用VS Code打开项目根文件夹；或者使用Typora逐个打开md文档
3. assets内拓扑md文档，图片使用**相对路径 `./xxx.svg`**，克隆后可直接渲染拓扑图
4. config目录下为配置模板，**不可直接上线，需要修改IP、Router‑ID、密码等参数**，参考config/readme.md
