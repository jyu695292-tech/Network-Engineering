## 1 系统概述
本校园网络采用**核心‑汇聚‑接入三层架构**。

- 外网边界：USG6000防火墙，实现NAT、安全策略、IPSEC VPN。
- 核心层：CE6855两台，Eth‑Trunk聚合、VRRP冗余，OSPF Area 0全网路由。
- 汇聚层：4台S5735‑S48S，OSPF邻居，向下对接接入交换机。
- 接入层：S5735‑P24P POE交换机，为面板AP提供POE供电。
- 无线：AC6805旁挂核心，统一管理所有Fit AP。

业务分区：外网区、DMZ服务器区、宿舍办公业务区。

### 业务规划摘要
| 业务区域     | VLAN   | 网段            | VRRP虚拟网关   | 说明               |
| ------------ | ------ | --------------- | -------------- | ------------------ |
| 管理VLAN     | VLAN99 | 192.168.99.0/24 | 192.168.99.254 | 设备管理网段       |
| 宿舍业务VLAN | VLAN10 | 10.10.0.0/16    | 10.10.0.254    | 宿舍PC、无线终端   |
| 服务器DMZ区  | VLAN20 | 10.20.0.0/24    | 10.20.0.254    | Portal、业务服务器 |

- 路由：全网OSPF Area 0；防火墙下发默认路由。
- 链路聚合：两台核心之间Eth‑Trunk1 LACP模式。
- 传输介质：上行OS2万兆单模光纤；接入层CAT6六类网线。

## 3 日常运维操作规范
> ⚠️重要：所有配置变更操作尽量在业务低峰期执行（凌晨维护窗口）；变更前必须完成配置备份，填写变更记录。

### 3.1 登录方式
1. SSH远程登录（日常维护优先）
2. Console串口本地登录：设备故障、密码丢失、设备初始化时使用。

> 禁止业务高峰期直接断电重启交换机、防火墙设备。

### 3.2 华为VRP常用查看命令
```bash
display version                  #查看设备软件版本
display device                   #查看硬件模块状态
display interface brief          #查看接口简要状态
display current-configuration   #查看设备当前运行配置
display ospf peer brief          #查看OSPF邻居简要信息
display vrrp brief               #查看VRRP状态
display eth-trunk 1              #查看聚合链路状态
display poe brief                #POE交换机查看供电状态
display ap all                   #AC控制器查看全部AP在线状态
display cpu-usage                #查看CPU利用率
display memory-usage             #查看内存利用率
display fan                      #查看风扇状态
display temperature              #查看设备温度
display logbuffer                #查看设备日志
```

## 4 定期巡检项目
### 每日巡检
1. CPU、内存利用率，CPU长期大于70%需要排查业务异常。
2. 接口状态：确认上行万兆光纤接口无Down，无大量错包、丢包。
3. OSPF邻居状态，邻居关系全部达到Full状态。
4. VRRP状态：一台Master，一台Backup，无频繁切换记录。
5. AC控制器：在线AP数量，大批量AP离线及时排查链路与供电。

### 每周巡检
1. 风扇、设备温度，确认设备无高温告警。
2. 读取设备日志，收集告警、报错信息。
3. 防火墙会话数、安全策略命中情况检查。

### 每月巡检
1. 全部网络设备配置备份。
2. 机房环境巡检：机房温度、供电状态、ODF光纤接头是否松动。
3. 业务抽样测试：宿舍上网、服务器访问、无线网络接入测试。

## 5 配置备份与恢复
### 5.1 配置备份
1. 设备本地保存配置：`save`
2. 通过FTP将`vrp.cfg`配置文件导出备份。
> 建议搭建FTP服务器，定期自动备份所有网络设备配置。
> 备份文件命名示例：`CoreA_20260808.cfg`，备份文件至少留存30天。

### 5.2 配置恢复
误配置、配置损坏时导入备份配置：
1. 将备份cfg上传至设备Flash。
2. 设置启动配置文件：`startup saved-configuration xxx.cfg`
3. 执行`reboot`重启设备生效。

> 恢复配置会中断业务，必须在维护窗口操作。

## 6 版本升级操作步骤
1. 获取新版本固件，确认硬件、License版本兼容性。
2. 升级前完整备份设备配置。
3. FTP上传系统`.cc`固件文件至设备Flash。
4. 设置下次启动系统文件：`startup system-software xxx.cc`
5. 执行`reboot`重启设备。
6. 设备启动完成，`display version`确认版本；检查接口、OSPF、VRRP、业务是否正常。

> 双核心升级顺序：优先升级备机；备机业务验证正常，切换业务后再升级主机。

## 7 典型故障处理排错
### 故障1：部分宿舍网段全部断网
1. 确认接入交换机接口状态是否Down，检查POE交换机供电。
2. 检查上行光纤链路、ODF配线架，光纤接头是否松动、脏污。
3. 确认Trunk接口允许VLAN10、VLAN99放行。
4. 检查汇聚设备OSPF邻居是否为Full状态。

### 故障2：大量无线AP离线
1. AC执行`display ap all`查看AP注册状态。
2. 检查POE交换机POE供电是否正常。
3. 确认AP管理VLAN99放通，AC与AP网络可达。

### 故障3：内网互通，全部终端无法访问互联网
1. 检查防火墙与核心设备上联接口状态。
2. 确认OSPF默认路由是否正常下发。
3. 检查防火墙NAT策略、安全策略是否生效。
4. 在防火墙设备测试外网连通性。

### 故障4：VRRP网关频繁切换
1. 检查核心之间Eth‑Trunk链路是否丢包抖动。
2. 排查设备CPU占用过高问题。
3. 检查VLANIF网关接口是否存在接口抖动。

### 故障5：OSPF邻居无法建立
1. 接口物理UP；两端接口同一网段；Area ID一致。
2. 接口网段宣告进入OSPF进程。
3. 不存在ACL阻断OSPF组播报文。
4. Router‑ID不冲突。

## 8 License维护
1. 防火墙USG6000、AC6805控制器需要License授权。
2. 查看授权信息命令：`display license`。
3. 关注授权到期时间，提前申请激活文件。
4. 硬件更换设备，需要对原有License做解绑，重新申领授权。

## 9 安全运维要求
1. 定期更新设备密码，使用高强度密码，禁止弱口令。
2. 配置ACL，仅允许管理网段访问设备SSH服务。
3. 闲置不用物理接口执行shutdown关闭。
4. 定期导出设备日志，留存安全事件记录。
5. 修改防火墙安全策略必须留存变更记录，禁止随意放开策略。
