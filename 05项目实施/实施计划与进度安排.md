## 1 项目实施总体规划
### 1.1 实施目标与范围
1. 实施目标：60日历天内完成四大片区34栋宿舍楼的无线网络改造，开学前正式上线运行，各项指标达到需求设计标准。
2. 实施范围：综合布线施工、设备安装上架、全网设备调试、认证系统对接、试运行与竣工验收、运维交接培训。
3. 实施原则：安全第一、质量优先、进度可控、最小影响，施工过程最大限度降低对学生正常生活的干扰。

### 1.2 项目组织架构
1. 项目经理：总负责项目进度、质量、成本、安全，协调校方与各方资源。
2. 技术负责人：负责方案落地、技术难题攻关、配置审核与测试验收。
3. 施工班组：分为4个片区施工组，负责各区域布线、设备安装与端接。
4. 调试组：负责核心、汇聚、接入、无线设备的配置与全网联调。
5. 质检组：负责施工过程质量巡检、链路测试、竣工验收核验。
6. 安全管理员：负责现场施工安全、用电安全、人员安全管理。

### 1.3 总体工期计划
项目总工期60日历天，分六个阶段实施，确保开学前交付：
1. 项目准备阶段：第1-7天，共7天
2. 综合布线施工阶段：第8-37天，共30天
3. 设备安装部署阶段：第30-39天，共10天（与布线后期并行）
4. 全网联调测试阶段：第40-47天，共8天
5. 试运行与优化阶段：第48-54天，共7天
6. 竣工验收与割接阶段：第55-60天，共6天

## 2 分阶段实施内容
### 2.1 项目准备阶段
1. 技术交底：向施工、调试人员进行方案交底、规范交底、安全交底。
2. 现场复核：复核所有楼栋弱电间、桥架、管线、点位位置，修正设计偏差。
3. 物料备货：完成所有设备、线缆、辅材的采购、到货与验货。
4. 工具准备：准备熔接机、网线测试仪、光功率计、施工工具与安全防护用品。
5. 校方协调：确认施工时段、进场权限、水电接驳点、垃圾清运方式。

### 2.2 综合布线施工阶段
1. 垂直光缆敷设：完成四大区域骨干光缆与楼栋垂直光缆敷设、熔接与测试。
2. 水平布线施工：按楼层逐间宿舍布放六类网线，两端做好临时标识。
3. 端接与配线：完成弱电间配线架端接、ODF熔接、宿舍面板底盒安装。
4. 链路测试：每条网线做通断、长度、串扰、衰减测试，每条光缆做光功率损耗测试，不合格链路立即整改。
5. 施工方式：四大片区同步并行施工，每栋楼自上而下逐层作业，当日垃圾当日清理。

### 2.3 设备安装部署阶段
1. 机柜安装：完成核心机房、区域机房、楼栋弱电间的机柜、机架安装固定。
2. 设备上架：核心、汇聚、接入交换机、防火墙、AC等设备依次上架，接电自检。
3. AP面板安装：宿舍内AP面板固定安装，接上网线确认供电正常、指示灯正常。
4. 标签粘贴：完成所有设备、线缆、端口、配线架的标准化标签粘贴。

### 2.4 全网联调测试阶段
1. 核心层调试：配置核心交换机VLAN、路由、DHCP、ACL等基础功能。
2. 汇聚接入层调试：配置汇聚交换机链路聚合、OSPF路由、VLAN透传；配置接入交换机端口VLAN、POE、端口安全、DHCP Snooping。
3. 无线系统调试：配置AC控制器，完成所有AP注册上线，配置SSID、射频参数、漫游、负载均衡等功能。
4. 安全认证调试：配置防火墙安全策略，对接校园统一身份认证系统，完成Portal认证全流程测试。
5. 全网连通性测试：测试各VLAN互通、外网访问、认证登录、漫游切换等核心功能。

### 2.5 试运行与优化阶段
1. 全网空载试运行7天，监控设备运行状态、链路利用率、AP在线率。
2. 分区域进行压力测试，验证晚高峰并发接入能力、带宽保障能力。
3. 根据现场信号测试结果，微调AP信道与功率，优化覆盖效果。
4. 收集试运行期间问题，逐项整改优化，确保各项指标达到设计要求。

### 2.6 割接上线与验收
1. 割接时间窗口：选择夜间低峰时段进行业务割接，最大限度减少影响。
2. 割接步骤：确认新网络运行正常 → 切换学生区出口路由至新网络 → 验证认证与上网业务 → 观察2小时无异常后割接完成。
3. 回滚方案：若割接出现重大故障，立即将路由切回原有网络，排查问题后二次割接。
4. 竣工验收：校方组织验收，出具验收报告，项目正式交付。

## 3 施工管理规范
### 3.1 现场施工管理
1. 施工时段：工作日8:00-12:00、14:00-22:00，午休与深夜禁止噪音施工；节假日根据校方要求调整。
2. 人员管理：施工人员统一佩戴工牌，遵守校园管理规定，严禁进入非施工区域。
3. 现场卫生：每日施工结束后清理现场垃圾，包装材料统一回收清运，保持宿舍区整洁。
4. 成品保护：施工过程中保护原有墙面、地面、门窗、桥架等设施，损坏及时修复。

### 3.2 施工安全规范
1. 用电安全：临时用电采用带漏电保护的配电箱，严禁私拉乱接；设备接电前确认电压规格。
2. 高空作业：2米以上作业必须使用合格梯具，佩戴安全帽，严禁单人高空作业。
3. 消防安全：施工现场严禁吸烟，配备灭火器材；动火作业提前报备校方。
4. 网络安全：施工过程中严禁触碰原有在用网络设备与链路，防止现有网络中断。

## 4 质量管控与验收标准
### 4.1 质量管控体系
实行三级质检制度：施工班组自检 → 项目质检组巡检 → 校方抽检验收。关键工序（光缆熔接、链路测试、核心配置）必须经质检合格后方可进入下一工序。

### 4.2 布线工程验收标准
1. 符合《综合布线系统工程验收规范》GB 50312-2016。
2. 六类链路各项电气参数达标，通过率100%。
3. 光缆熔接损耗符合标准，链路光功率在允许范围内。
4. 标签完整清晰，路由规范，理线整齐。

### 4.3 设备与性能验收标准
1. 设备型号、数量、配置与设计方案一致，硬件完好无损伤。
2. 所有设备正常运行，端口、功能全部可用，配置符合规范。
3. 无线性能验收：宿舍内信号强度≥-65dBm，丢包率≤1%，漫游切换时延＜50ms。
4. 认证与安全验收：Portal认证正常，日志留存完整，隔离策略生效。

### 4.4 文档验收
交付全套项目文档：需求说明书、设计方案、配置脚本、测试报告、验收报告、运维手册等。

## 5 项目风险与应对措施
### 5.1 进度风险
- 风险：施工滞后、物料到货延迟导致无法按期交付。
- 应对：提前备货，预留3天缓冲工期；增加施工人员，多楼栋并行作业；关键工序加班赶工。

### 5.2 技术风险
- 风险：设备兼容性问题、认证对接失败、原有网络割接故障。
- 应对：设备到货后先进行实验室预测试；认证系统提前联调；割接制定详细回滚方案。

### 5.3 安全风险
- 风险：施工人员受伤、误碰原有网络造成断网。
- 应对：全员安全培训，安全员全程巡检；施工前确认管线路由，严禁触碰未知线缆。

## 6 运维交接与培训
### 6.1 文档交付
项目验收后交付完整文档资料，包括但不限于：
1. 全套设计方案、配置脚本、设备清单。
2. 测试报告、验收报告、竣工图纸。
3. 设备原厂资料、运维操作手册、故障处理手册。

### 6.2 运维培训
1. 理论培训：网络架构、设备原理、认证流程、安全策略讲解。
2. 实操培训：设备登录、配置查看、常见故障排查、AP管理操作。
3. 应急培训：网络中断、设备故障、认证异常等场景的应急处理流程。
